# 💰 Smart Expense Tracker

A Django-based web application designed to help users manage, track, and monitor their daily expenses efficiently.

## 🚀 Features

- User Registration, Login and Logout.
- Add, Edit and Delete Expenses.
- Dashboard with expense summaries.
- Displays Total Expenses and Expense Count.
- Tracks Highest and Monthly Expenses.
- Filter expenses by category.
- Individual expense management for each user.

## 🛠️ Technologies Used

- **Backend:** Python, Django
- **Frontend:** HTML, CSS
- **Database:** SQLite

## ⚙️ Installation and Setup

**1. Clone the repository**
```bash
git clone https://github.com/Shenika10/Smart-Expense-Tracker.git
```

**2. Navigate to the project folder**
```bash
cd Smart-Expense-Tracker
```

**3. Create and activate a virtual environment**
```bash
python -m venv venv
venv\Scripts\activate
```

**4. Install Django**
```bash
pip install django
```

**5. Apply migrations**
```bash
python manage.py migrate
```

**6. Run the application**
```bash
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.

## 🎯 Project Objective

To provide a simple and user-friendly platform for recording expenses, monitoring spending habits, and managing personal finances.
